ROADWATCH WEBSITE STARTER
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html > Open with Live Server.
5. Submit a test report and inspect My Reports, Admin and Manage Reports.

PAGES: index.html, login.html, report.html, results.html, my-reports.html, map.html, admin.html, manage-reports.html.

IMPORTANT:
This is a FRONTEND PROTOTYPE. It stores data in browser localStorage, not MySQL.
Login is a display-name demo, not secure authentication.
Actual YOLO AI detection is NOT connected yet. The result page clearly identifies this.
The map uses Leaflet/OpenStreetMap and requires internet access.
Next: build Flask APIs, connect SQLite/MySQL, integrate YOLO, and add secure authentication/authorization.
